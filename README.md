# 中学生交互式光学设计编程项目

## How to Run

```bash
# Docker 运行（推荐，构建阶段会自动校验统一规则清单）
docker-compose up --build -d

# 访问应用
# 用户端: http://localhost:8081

# 或直接用浏览器打开 frontend-user/index.html
```

## 口径校验（本地开发与构建共用同一份清单）

题目、帮助文案、参数面板、结果弹窗与画布渲染共用同一份规则与示例数据：
`frontend-user/js/spec.js`（OPTICS_SPEC）。

```bash
# 本地开发：无需安装依赖，Node 18+ 即可
npm test

# Docker 构建：同样执行该校验，任一项不通过镜像构建失败
# 校验内容包括：平面透镜侧移、非球面精准汇聚、球差、色散焦点、文案口径
```

测试脚本 `tests/optics.test.js` 直接加载浏览器运行时的 `spec.js / config.js /
physics.js`，确保“被测试的就是画布实际运行的代码”。

## 光路规则（画布实际效果与文案以此为准）

- 凸透镜：平行光会聚，边缘光线因球差会聚在稍靠近透镜的位置
- 凹透镜：光线发散，反向延长线交于虚焦点（空心标注）
- 平面透镜：垂直入射方向不变且无侧移；斜入射发生可见侧移，出射光与入射光平行
- 非球面透镜：各条平行光线精准汇聚到同一焦点
- 色散（工具栏“色散”开关）：红/绿/蓝焦点随颜色前后变化，普通玻璃分离明显，低色散镜片几乎重合

## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜：光线向光轴会聚，边缘光线存在球差
- 凹透镜：光线向外发散（虚焦点）
- 平面透镜：垂直入射不偏折不侧移；斜入射侧移但方向不变
- 非球面透镜：精准会聚，消除球差
- 色散：红/绿/蓝焦点随颜色变化，低色散镜片几乎重合

### 技术栈

HTML5 + CSS3 + JavaScript（原生无依赖）
